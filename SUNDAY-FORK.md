# Sunday downstream fork

This public fork tracks `block/buzz` under the Apache License 2.0.

Its purpose is to produce auditable Buzz builds for a private, self-hosted deployment. Deployment configuration, identity credentials, channel identifiers, private workspace material and user content must never be committed here.

Upstream changes are adopted as reviewed, pinned commits. Downstream product changes are developed through reviewable branches and pull requests. Runtime images publish under `ghcr.io/geojofori/buzz`.
